# Line Grouper

Тестовое задание для вакансии Java-разработчик в UNO Soft.

Программа считывает файл со строками вида `"A1";"B1";"C1"`, находит уникальные строки и группирует их по критерию: если две строки имеют одинаковое непустое значение в одной и той же колонке — они принадлежат одной группе.

## Сборка

```bash
mvn clean package
```

## Запуск

```bash
java -Xmx1G -jar target/line-grouper-1.0-SNAPSHOT.jar <путь_к_файлу>
```

Результат записывается в `output.txt` в текущей директории.

## Результат на lng.txt (1 000 000 строк)

- Групп с более чем одним элементом: **1910**
- Время выполнения: **~2 сек**

## Алгоритм

Union-Find (Disjoint Set Union) с path compression и union by rank. Для каждой колонки строится маппинг `значение → первая строка` — при повторном появлении значения строки объединяются в одну группу.
